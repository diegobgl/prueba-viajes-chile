## Proyecto principal

[Programación avanzada: campañas y anuncios](programacion-avanzada/README.md)

La prueba 792246 modela campañas publicitarias con anuncios de Video, Display y Social. Aplica abstracción, herencia, composición, encapsulación, validación de datos y manejo de excepciones. Incluye una demostración por consola y 17 pruebas automatizadas.

Tecnología: Python 3.12 o superior, biblioteca estándar y unittest. Los métodos de procesamiento multimedia son mensajes didácticos. El proyecto no procesa archivos de video o imágenes ni representa un servicio desplegado.

## Ejecutar y verificar

Desde la carpeta `portafolio/programacion-avanzada`:

```shell
python -m unittest discover -v
python demo.py
```

[Resultado de pruebas](programacion-avanzada/VALIDACION.txt) y [evidencia de consola](programacion-avanzada/EVIDENCIA_DEMO.txt).
